Aide — admin du site

Chaque ligne rappelle où cliquer ; déplie-la pour le mode d'emploi complet.

Les bases

Se connecter #▶ Se connecter avec GitHub — la première fois, il faut un compte GitHub invité par Pierre.

L'admin est à l'adresse nouveau.faiscommecheztoi.ch/admin (à mettre en favori — l'ancienne adresse faiscommecheztoi.ch/admin y renvoie). GitHub est l'endroit où les fichiers du site sont rangés : un compte GitHub sert simplement de badge d'accès.

La première fois seulement :

  1. Créer un compte gratuit sur github.com (e-mail + mot de passe, 2 minutes).
  2. Envoyer le nom d'utilisateur choisi à Pierre, qui envoie une invitation. Elle arrive par mail : cliquer pour l'accepter.
  3. Revenir sur l'admin → Se connecter avec GitHub → autoriser une fois.

Ensuite le navigateur reste connecté. Le second bouton, Se connecter avec un jeton d'accès, est un dépannage technique : ne pas l'utiliser.

Message « Votre domaine n'est pas autorisé à utiliser l'authentificateur » → ce n'est pas toi, c'est un réglage côté Pierre. Lui écrire.
Enregistrer et voir le résultat en ligne #▶ Enregistrer (en haut à droite) → en ligne 2 à 3 minutes plus tard → recharger avec Ctrl+Maj+R.

Le site n'a pas de base de données comme l'ancien WordPress : chaque enregistrement réécrit un fichier, puis le site se reconstruit tout seul. Compter 2 à 3 minutes avant que la modification soit visible — inutile de recharger frénétiquement.

  • Tant que tu n'as pas cliqué Enregistrer, rien n'est publié : on peut fermer la fiche sans crainte.
  • Si la modification n'apparaît pas après 3 minutes : recharger en vidant le cache, Ctrl+Maj+R (Cmd+Maj+R sur Mac).
  • Chaque enregistrement est archivé : on peut toujours revenir à une version précédente (demander à Pierre).
L'aperçu à droite, c'est le vrai site #▶ Le volet de droite montre la page telle qu'elle sera, et se met à jour pendant qu'on tape. Rien n'est en ligne tant qu'on n'a pas enregistré.

Quand une fiche est ouverte, la moitié droite de l'écran est le site lui-même, ouvert sur la section qu'on modifie : le texte, les photos, l'ordre des fiches changent sous les yeux, sans rien enregistrer. C'est un brouillon : le site en ligne, lui, ne bouge qu'après Enregistrer (et 2 à 3 minutes).

  • Une fiche artiste s'ouvre déjà retournée, sous l'onglet de son année ; on peut la re-cliquer pour voir le recto, cliquer les années, faire défiler la page.
  • Une photo qu'on vient de choisir s'affiche tout de suite, même avant l'enregistrement.
  • Le volet est plus étroit qu'un écran d'ordinateur : c'est normal si la page s'affiche comme sur une tablette.
  • Volet vide ou disparu ? Le bouton d'aperçu de la barre d'outils de l'éditeur (en haut à droite, icône d'œil) le rouvre.
Retrouver une fiche #▶ Barre de recherche en haut → taper un nom. Ou la rubrique dans la colonne de gauche.

La colonne de gauche liste tout ce qui est modifiable :

Sous Fichiers, un clic sur une section ouvre directement son formulaire — pas de liste intermédiaire. Et avec plus de 70 fiches artistes, la recherche (champ en haut au centre) est souvent la plus rapide : elle cherche dans toutes les rubriques.

Artistes

Corriger le titre d'un spectacle (ou n'importe quel champ d'une fiche) #▶ Artistes → la fiche → champ Titre du spectacle → Enregistrer.
  1. Colonne de gauche → Artistes (ou taper le nom dans la recherche). La liste s'ouvre sur l'édition en cours, avec la photo de chaque artiste en vignette ; pour une édition passée, le menu Filtrer en haut de la liste.
  2. Cliquer sur la ligne de l'artiste. La liste affiche ordre. Nom — Titre du spectacle.
  3. Dans la fiche, corriger le champ voulu. L'aperçu à droite se met à jour en direct.
  4. Enregistrer, en haut à droite.

Même principe pour la durée, le lieu, les horaires, l'école, la biographie… Un champ laissé vide ne s'affiche pas sur le site : mieux vaut vide que « — ».

Ajouter un·e artiste #▶ Artistes → Nouveau (en haut à droite) → remplir → Enregistrer. Année = 2026, Ordre = rang de la première représentation.

Chaque fiche devient une carte qui se retourne sur le site : photo et nom au recto, tout le reste au verso.

Changer ou ajouter la photo d'un·e artiste #▶ Fiche → champ Photos → ajouter / remplacer l'image. La première de la liste est celle qui s'affiche.
  1. Ouvrir la fiche de l'artiste, descendre jusqu'à Photos.
  2. Sur une photo existante : cliquer l'image pour la remplacer (choisir un fichier de l'ordinateur, ou une image déjà envoyée).
  3. Pour en ajouter une : le bouton d'ajout sous la liste, puis remplir Texte alternatif (souvent le nom de l'artiste suffit) et Crédit photo.
  4. L'ordre compte : la première photo s'affiche sur la carte, les suivantes se feuillettent. Pour changer la photo principale, remonter la bonne en première position avec les flèches.
  5. Enregistrer.
Portraits verticaux de préférence (les cartes sont en hauteur, un panorama sera rogné) ; au moins 1000 px de large ; pas le fichier de 10 Mo sorti de l'appareil photo — le site redimensionne, mais l'envoi sera long. Voir Les règles pour les images.
Changer l'ordre des artistes #▶ Artistes → bouton Réorganiser (en haut de la liste) → glisser les fiches → Terminer.

Le plus simple : dans la liste Artistes, cliquer Réorganiser. Les fiches se regroupent par édition et se déplacent à la souris (ou au doigt) ; en terminant, la numérotation est réécrite automatiquement, édition par édition. On ne peut pas déplacer une fiche d'une édition à l'autre — pour ça, changer son champ Année.

L'autre méthode marche toujours : ouvrir la fiche et taper le numéro dans le champ Ordre. Les artistes apparaissent sur le site dans l'ordre de ce champ, du plus petit au plus grand, à l'intérieur de leur année. La convention : numéroter selon la première représentation de chacun·e. Deux fiches peuvent porter le même numéro si elles sont d'années différentes.

Retirer un·e artiste #▶ Fiche → Supprimer (en haut). Pour une annulation, préférer laisser la fiche et adapter le texte.

Dans la fiche ouverte, le bouton Supprimer est en haut, à côté de Dupliquer. La fiche disparaît du site au prochain rebuild.

Supprimer est réversible, mais seulement par Pierre (tout est archivé). Dans le doute — spectacle annulé, artiste remplacé·e — il est plus simple de modifier la fiche que de la supprimer.
Ajouter l'affiche d'une nouvelle édition #▶ Éditions → Nouveau → Année → Affiches (image + crédit graphiste) → Enregistrer.

Une entrée par édition. Le champ Année doit être identique à celui des fiches artistes de cette édition (ex. 2026) : c'est ce qui fait apparaître l'onglet dans la section Artistes. On peut mettre plusieurs affiches si l'édition en a eu plusieurs.

Pour une nouvelle édition, demander aussi à Pierre de mettre à jour le filtre par défaut de la liste Artistes (un réglage dans la configuration de l'admin), pour qu'elle s'ouvre sur la nouvelle année.

Textes du site

Modifier l'intro, les Infos pratiques, Participer, Contact & Team #▶ Colonne de gauche, groupe Fichiers → la section → le texte → Enregistrer.
SectionCe qu'elle contient
Intro (haut de page)Le texte d'accueil et la photo d'ambiance
Infos pratiquesTitre + texte
ParticiperTitre + texte (conditions, garanties, calendrier de l'appel)
Contact & TeamTitre + texte — un bloc par personne : nom, rôle, e-mail

Dans Contact & Team, pour garder une personne par bloc avec des retours à la ligne simples, terminer chaque ligne par un retour à la ligne (pas une ligne vide entre nom, rôle et e-mail ; une ligne vide entre deux personnes).

Gras, italique, liens #▶ Sélectionner le texte → la barre d'outils au-dessus du champ. Rien d'autre n'est réglable : le design est fixe.

Dans les zones de texte long (sections, biographies), la barre d'outils permet le gras, l'italique et les liens (sélectionner le texte, icône de lien, coller l'adresse — pour un e-mail : mailto:contact@faiscommecheztoi.ch).

Couleurs, tailles, positions, ordre des sections : ça appartient au design de Siméon et ne se règle pas depuis l'admin. Pour ce genre de demande, passer par Pierre.

Afficher ou masquer le nuage « Appel à projet » #▶ Colonne de gauche → Nuage « Appel à projet » → case Visible → Enregistrer.
  • Visible : l'interrupteur. Coché à l'ouverture de l'appel, décoché à la clôture.
  • Texte : ce qui est écrit dans le nuage (court : « Appel à projet »).
  • Lien : où il envoie. #participer fait défiler vers la section Participer ; une adresse complète (https://…) ouvre une page externe, par exemple le formulaire.

Logos et partenariats

Ajouter ou retirer un logo de soutien #▶ Colonne de gauche → Soutiens (logos) → liste Logos → ajouter / supprimer → Enregistrer.

Chaque logo = une image, un Nom (affiché si l'image ne charge pas, et lu par les lecteurs d'écran) et, si on veut, un Lien vers le site de l'institution. L'ordre de la liste est l'ordre d'affichage : les flèches déplacent un logo.

Format idéal : PNG à fond transparent, ou SVG. Éviter les logos en JPEG avec un fond blanc, ils font un rectangle sur le fond rose.

Modifier ou ajouter un partenariat #▶ Partenariats → la fiche (ou Nouveau) → Nom, Ordre, Texte → Enregistrer.

Un partenariat = un nom, un ordre d'affichage et un texte. Ils s'affichent dans la section Partenariats, triés par Ordre — modifiable aussi par glisser-déposer avec le bouton Réorganiser, en haut de la liste.

Images

Les règles pour les images #▶ JPEG pour les photos, PNG/SVG pour les logos · ≥ 1000 px de large · crédit photo rempli · texte alternatif court.
  • Photos d'artistes : JPEG, portrait vertical, au moins 1000 px de large, idéalement moins de 2 Mo. Le site fabrique lui-même les tailles nécessaires.
  • Affiches : JPEG, le format de l'affiche, 1200 px de large suffit.
  • Logos : PNG à fond transparent ou SVG.
  • Crédit photo : toujours (il s'affiche sur la fiche). Texte alternatif : une courte description pour les personnes non-voyantes — le nom de l'artiste, le nom de l'institution.
  • Une image déjà envoyée est réutilisable : dans le sélecteur d'image, l'onglet des fichiers existants. Le bouton image en haut à gauche de l'admin ouvre la bibliothèque complète.

Quand ça coince

J'ai enregistré et je ne vois rien sur le site #▶ Attendre 3 minutes → Ctrl+Maj+R. Toujours rien après 10 minutes → écrire à Pierre.

Le site se reconstruit après chaque enregistrement, ça prend 2 à 3 minutes. Ensuite le navigateur peut encore afficher l'ancienne version en cache : recharger avec Ctrl+Maj+R (Cmd+Maj+R sur Mac). Vérifier aussi que la fiche a bien été enregistrée (le bouton Enregistrer redevient grisé) et, pour une fiche artiste, que le champ Année correspond à l'onglet que tu regardes.

J'ai fait une bêtise #▶ Rien n'est perdu : chaque enregistrement est archivé. Écrire à Pierre en disant quoi et quand.

Texte effacé, mauvaise photo, fiche supprimée : tout est récupérable, parce que chaque enregistrement est une version conservée. Dis à Pierre ce qui a été touché et à quelle heure environ, il restaure. Inutile d'essayer de « réparer » en retapant de mémoire.

On peut être plusieurs à éditer ? #▶ Oui — sauf la même fiche au même moment.

Chacun·e avec son compte. Le seul cas à éviter : deux personnes qui enregistrent la même fiche à quelques secondes d'intervalle, la seconde écrase la première. Se répartir les fiches suffit.

Et l'ancien site WordPress ? #▶ Il n'existe plus : c'est ici qu'on édite. Les anciennes adresses redirigent.

Depuis la bascule, faiscommecheztoi.ch affiche le nouveau site. Les anciennes adresses WordPress (/les-artistes/, /contact/, /nos-soutiens/…) redirigent automatiquement vers les sections correspondantes, donc les liens publiés ailleurs continuent de marcher. L'ancien WordPress n'est plus servi : tout se modifie ici.
